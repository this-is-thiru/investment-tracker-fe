# Transactions Table Review

**Verdict:** NEEDS_FIXES

## Findings

1. **`src/app/features/investments-tracking/components/transactions-table/transactions-table.component.html:131-138`** — Type filter is implemented as a `<p-select>` dropdown (`typeFilterOptions`), but the spec explicitly mandates a "segmented control: All / BUY / SELL" (F2 — Filter Bar). The other filters (Asset Type, Broker, Date preset) are correctly dropdowns; only the Type filter is specified as segmented. Suggested fix: replace the `<p-select>` for type with a three-button segmented control bound to `filterType` (e.g., three buttons with `[ngClass]` highlighting the active value), and remove `typeFilterOptions` / its usage from the template.

2. **`src/app/features/investments-tracking/components/transactions-table/transactions-table.component.html:297` and `:469`** — Table sub-headers display `"Showing {{ filteredTemporary.length }} of {{ temporaryTransactions.length }}"` and the analogous portfolio copy. Spec F8 mandates the format "Showing X–Y of Z" (a range from current paginator offset to offset+rows). The implementation shows a single count, not a range, and ignores the paginator state. Suggested fix: bind to paginator state via template refs `#dtTemp` / `#dtPort` (e.g., `(onPage)` handler that tracks `first` and `rows`) and render `Showing {{ first + 1 }}–{{ min(first + rows, total) }} of {{ total }}`. Alternative: drop the `first`/`rows` machinery and match spec text exactly using a `first` field updated on `onPage`.

3. **`src/app/features/investments-tracking/components/transactions-table/transactions-table.component.html:443-457` and `:617-630`** — Spec edge case "Filter yields zero rows" requires "the 'Filtered out: N' hint appears" alongside the Reset CTA. The current zero-filter empty state shows only the heading, helper text, and Reset button. Suggested fix: in the `temporaryTransactions.length !== 0` / `portfolioTransactions.length !== 0` branches, add a helper line that computes `filteredOut = total - filtered.length` (e.g., via a getter on the component) and renders e.g. `Filtered out: {{ filteredOutTemp }} transactions.` between the description and the Reset button.
